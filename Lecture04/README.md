Lecture 04 – Z-Transforms and Transfer Functions

Part 1: A Signal and its Z-Transform


1. Identify the sample represented by each term in X(z).


The polynomial is X(z) = 1 + 2z^ {-1} + z^{-2}.

The constant 1 (or 1z^0) represents the sample at x[0] = 1.The term 2z^{-1} represents the sample at x[1] = 2.

The term z^{-2} represents the sample at x[2] = 1.

2. Write the Z-transform of the delayed signal.



The delayed signal sequence is [0, 1, 2, 1]. 

By pairing each value with its corresponding time index, the new Z-transform is:

X_{delayed}(z) = 0 + 1z^{-1} + 2z^{-2} + 1z^{-3}

X_{delayed}(z) = z^{-1} + 2z^{-2} + z^{-3}


3. Explain why delaying the signal by one sample multiplies X(z) by z^{-1}.

In the Z-domain, the variable z^{-1} physically represents a unit delay operator (a delay of exactly one sample). 

If you take the original transform $X(z)$ and multiply the entire equation by z^{-1}, the math expands perfectly to shift every single exponent down by one:

z^{-1} * (1 + 2z^{-1} + z^{-2}) = z^{-1} + 2z^{-2} + z^{-3}

This mathematical shift directly mirrors the physical shift of the sequence stepping forward in time.



Part 2: A System with One Sample Delay

4. Calculate y[0], y[1], y[2] and y[3] by hand. Compare them with MATLAB.


The system equation is y[n] = 0.5x[n] + 0.5x[n-1]. 

Given our padded input x = [1, 2, 1, 0]:

y[0] = 0.5(1) + 0.5(0) = 0.5

y[1] = 0.5(2) + 0.5(1) = 1.5

y[2] = 0.5(1) + 0.5(2) = 1.5

y[3] = 0.5(0) + 0.5(1) = 0.5

Comparison: The manual calculations yield [0.5, 1.5, 1.5, 0.5]. This is a perfect match to the output generated by MATLAB in the command window.



5. Explain how b = [0.5, 0.5] represents the two terms in H(z).

In MATLAB's filter(b, a, x) function, the vector b stores the numerator coefficients of the transfer function in ascending powers of z^{-1}(or chronological delays).

b(1) = 0.5 is the coefficient for z^0, representing the weight of the current input x[n].

b(2) = 0.5 is the coefficient for z^{-1}, representing the weight of the previous delayed input x[n-1].

6. Change the system to H(z) = 0.8 + 0.2z^{-1}. Explain which input sample now has more influence on the output.


With the updated coefficients b = [0.8, 0.2], the current input sample x[n] now has significantly more influence on the output (accounting for 80% of the result). 

The previous, delayed sample x[n-1] only contributes 20%. In an engineering context, this means the filter does less "smoothing" than the 50/50 split and reacts much faster to sudden changes in the active signal.
